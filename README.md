# Bouncing Balls

A simple SFML 3 application.
Click the left mouse button to create a randomly sized and colored ball that bounces off the window edges.

## Demo

https://github.com/user-attachments/assets/2c845c98-1133-4605-b498-aa262dee0be4

## Build

CMake and SFML 3 must be installed.

```sh
cmake -S . -B build
cmake --build build
```

Run:

```sh
./build/bouncing_balls
```
